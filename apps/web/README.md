# RIYAAZ web application

The web application is a Next.js and TypeScript application. It provides the
student and teacher user experience while treating the API as the source of
product data.

## Commands

Run these from the repository root after installing dependencies:

```text
npm run web:build
npm run web:lint
npm run web:test
```

Use `npm run dev --workspace=@riyaaz/web` for local development.
